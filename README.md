# Discord Activity Graph Viewer

A local viewer for seeing how your Discord message activity changes over time.

## Key features

- Explore daily, weekly and yearly activity.
- Filter conversations and inspect active days, hours and words.
- Process your export in the browser without uploading it.

## Get started

Open `index.html` in Chrome or Edge and select the messages folder from your Discord export. The interface is currently in Czech.
